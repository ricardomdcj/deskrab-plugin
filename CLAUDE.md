# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Public distribution repo for **Deskrab** (MIT): the Claude Code plugin, its marketplace, and the
firmware update page served by GitHub Pages from `docs/`. The source of truth is the **private**
repo `../deskrab` (github.com/ricardomdcj/deskrab).

- `plugin/`, `.claude-plugin/marketplace.json`, `docs/manifest.json` and `docs/firmware/` are
  generated by `python tools/publish.py` in the private repo. Don't edit them here; change the
  private repo and publish again.
- Hand-written here: `README.md` (customer-facing, Portuguese first), `docs/index.html`,
  `LICENSE`, `THIRD_PARTY_NOTICES.md`.
- Never commit firmware source code here, only the `.bin` images.
- The firmware page uses ESP Web Tools pinned to `esp-web-tools@10.3.0` (jsDelivr). The manifest
  flashes separate parts (bootloader 0x1000, partition table 0x8000, app 0x10000) so the device's
  NVS (touch calibration, Wi-Fi) survives updates.
- Customers install with `/plugin marketplace add ricardomdcj/deskrab-plugin`, then
  `/plugin install deskrab@deskrab` and `/deskrab:setup`.
- The user writes in Portuguese. Commit messages in Portuguese, with the Co-Authored-By line.
