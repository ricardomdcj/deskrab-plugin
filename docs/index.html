Deskrab · firmware

Instale ou atualize o firmware do display direto pelo navegador, sem instalar nada.

Antes de começar

  1. Use o Chrome ou o Edge num computador (o celular não funciona).
  2. Ligue o display no computador com o cabo USB (um cabo de dados, não só de carga).
  3. Libere a porta: no Claude Code, peça "pause o Deskrab para atualizar o firmware", ou rode deskrab_bridge.py pause.

Instalar

Este navegador não tem Web Serial. Abra esta página no Chrome ou no Edge, num computador. A página precisa ser aberta por HTTPS.

Versão disponível: carregando…

Escolha a porta do display na lista (CH340 ou USB Serial). A calibração do toque e o Wi-Fi continuam salvos, a menos que você marque a opção de apagar o aparelho.

Depois

  1. Volte ao Claude Code e peça "retome o Deskrab" (ou rode deskrab_bridge.py resume).
  2. O caranguejo reconecta em alguns segundos.

Primeira vez? Instale o plugin

No Claude Code:

/plugin marketplace add ricardomdcj/deskrab-plugin
/plugin install deskrab@deskrab
/deskrab:setup
